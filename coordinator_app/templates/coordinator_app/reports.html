Reports Center Guide

Learn how to use reports and features

Welcome to Reports Center

The Reports Center is your central hub for generating, downloading, and managing all academic and administrative reports for the {{ program }} program.

Quick Downloads

Click any report card to instantly generate and download reports in PDF, Excel, or Word format.

Smart Filters

Use dropdown filters to customize reports by status, section, date range, or student group.

Report History

View recently generated reports in the sidebar. Access download history and manage past reports.

Custom Reports

Build custom reports with specific data ranges and criteria at the bottom of the page.

Quick Tip

Reports are generated with real-time data from the database. What you download reflects the current state of enrollments and grades.

Enrollment Reports

Master List

Complete student enrollment list with status filtering

Features:

  • Filter by status: All Students, Approved, Pending, or Rejected
  • Available in PDF (formatted), Excel (for analysis), or Word (editable)
  • Includes: Student name, LRN, gender, contact info, section, status
  • Use case: Official documentation, board reports, archival
Enrollment Analytics

Comprehensive analytics with visual charts

Includes:

  • Enrollment status breakdown (approved, pending, rejected)
  • Gender distribution with percentages and visual charts
  • GWA distribution analysis
  • Key enrollment metrics and statistics
  • Use case: Data-driven decision making, program evaluation, reports to administration

Section Reports

Class Lists by Section

Student roster for each class section

How to Use:

  • Select "All Sections" to generate lists for all classes
  • Or choose specific section (e.g., STE-1) for single class list
  • PDF format: Numbered list with student names and LRN
  • Excel format: Sortable spreadsheet with full details
  • Word format: Editable document for customization

Contains:

  • Student names (numbered 1-40)
  • LRN, gender, parent contact information
  • Section name, room number, and adviser
  • Use case: Attendance, parent contact lists, classroom management
Section Analytics

Comprehensive section analytics with visual charts

Includes:

  • Section Balance Chart: Visual representation of student distribution across sections
  • Section GWA Comparison: Average GWA per section with rankings
  • Capacity Utilization: Fill rates, available slots, and balance indicators
  • Performance Metrics: Section-wise academic performance analysis
  • Use case: Balancing sections, identifying high/low performing classes, capacity planning

Academic Reports

Academic Rankings

Honor roll and GWA rankings with filtering

Filter Options:

  • Honor Students Only: Students with GWA ≥ 90
  • All Students Ranked: Complete ranking from highest to lowest
  • Top 20 Students: Top performers only

Contains:

  • Rank, student name, section, GWA (to 2 decimals)
  • Subject grades breakdown
  • Honors classification (With Honors, High Honors, Highest Honors)
  • Use case: Awards ceremonies, scholarship applications
Subject Grades Summary

Complete grade data in Excel format

Excel Layout:

  • One row per student with columns for each subject
  • Math, Science, English, Filipino, etc. as separate columns
  • GWA column and remarks column included
  • Can be sorted, filtered, and analyzed with pivot tables
  • Use case: Grade analysis, identifying weak subjects, data reporting
At-Risk Students

Students needing academic intervention

Identifies students with:

  • GWA below 80 (failing threshold)
  • Failing grades in specific subjects
  • Concerning grade trends (declining performance)
  • Includes intervention recommendations and previous period comparison
  • Use case: Early intervention, tutoring programs, parent conferences
Report Cards (Batch)

Generate individual report cards with certificates

How it Works:

  • Select section or "All Sections"
  • System generates individual PDF for each student
  • Automatically includes honor certificates for qualifiers (GWA ≥ 90)
  • Downloads as single ZIP file or merged PDF

Each Report Card Contains:

  • Student info header, school year, grading period
  • Subject grades table, GWA, attendance record
  • Teacher remarks, school seal, signatures
  • Use case: End of grading period distribution to parents/students

Administrative Reports

Program Summary

Comprehensive program overview with period selection

Period Options:

  • Current Period, 1st Quarter, 2nd Quarter, Semester, or Annual

Comprehensive Summary Includes:

  • Program overview and description
  • Total enrollment statistics and trends
  • Academic performance summary (avg GWA, honor roll %)
  • Section distribution and gender demographics
  • Key achievements, challenges, and recommendations
  • Monthly enrollment data when applicable
  • Use case: School board presentations, annual reports, program evaluation
Activity Log

Audit trail of coordinator actions

Tracks All Actions:

  • Date/timestamp, coordinator name, action performed
  • Affected student/section, before/after values for edits
  • IP address and session ID for security
  • Sorted chronologically (most recent first)
  • Use case: Audit purposes, tracking changes, troubleshooting, accountability
Templates & Forms

Blank forms and editable templates

Available Templates:

  • Narrative Report Template (Word): Pre-formatted template with sections for Executive Summary, Introduction, Performance, etc.
  • Enrollment Form (PDF): Blank student enrollment form
  • Section Transfer Form (PDF): Form for section reassignment requests
  • Parent Consent Form (PDF): Consent form with signature lines
  • Grade Sheet Template (PDF): Blank grade recording sheet with 40 rows
  • Use case: Manual data collection, backup forms, customized reporting

Custom Report Builder

Build Custom Reports

Located at the bottom of the Reports Center page, the Custom Report Builder lets you create tailored reports with specific criteria that aren't covered by the standard report cards.

Step-by-Step Guide:
1

Select Data Range

Choose time period: Current School Year, Last 30 Days, Last Quarter, or Custom Range

2

Choose Report Format

Select PDF (for viewing/printing), Excel (for analysis), or Word (for editing)

3

Select Data to Include

Check boxes for: Student Demographics, Academic Grades, Section Assignments, Contact Information

4

Build Report

Click "Build Custom Report" button. System will generate and download your custom report.

Example Use Cases:
  • New Student Report: Last 30 days + Demographics only = List of recently enrolled students
  • Complete Data Export: Current year + All data types = Comprehensive Excel file for external analysis
  • Contact List: Current year + Demographics + Contact Info = Parent contact spreadsheet
  • Quarter Performance: 1st Quarter + Grades + Sections = Academic report for specific period

Need more help? Contact IT support or your program administrator
